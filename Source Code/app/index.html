TARKOVEYES / 0.20.0
Your personal raid notebook.
A standalone multi-map, quest and item-price companion with isolated PvP, PvE and Seasonal/Kord Breach profiles. Reads screenshot filenames, selected game logs and a temporary inventory crop when you press Shift+F8. OCR runs inside the app and the crop is not saved. No game memory access, game modification, input automation or accounts. Item prices connect only to tarkov.dev when you press Update prices.
This is an unofficial companion. There is no BSG or BattlEye endorsement or guarantee against sanctions.
